# Models Directory

This directory contains AI models and related files for the CLO/PLO Assessment Platform.

## Structure

- `ai_models/` - Main AI models (EraX-VL-7B-V1.5)
- `pretrained/` - Pre-trained models and embeddings
- `checkpoints/` - Model training checkpoints and backups

## Usage

Place the EraX-VL-7B-V1.5 model files in `ai_models/erax-vl-7b-v1.5/` directory.

Required files:
- config.json
- pytorch_model.bin
- tokenizer.json
- tokenizer_config.json
- vocab.txt
